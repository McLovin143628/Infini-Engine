# Blank 3D template

The starter scene `inf new --template blank-3d` scaffolds: a ground plane, a
directional sun and a camera. Three entities — a starting point, not a demo.

It exists so the default template produces a project that **cooks and runs**:
`inf new My Game` then `inf cook --project "My Game"` then
`inf-player --pack "My Game/Build" --headless --run-frames 300 --assert-exit`.

Generated by `inf_editor_core::samples::blank3d_scene`. Regenerate with
`INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.
