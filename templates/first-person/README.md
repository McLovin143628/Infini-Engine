# First Person template

The starter scene `inf new --template first-person` scaffolds: a 3D ground
plane, a directional sun, a kinematic **Player** capsule that is a real pawn
(`CharacterController3D` + `CharacterMovement { player_controlled }`), and a
first-person **Camera** at eye height.

Press Play and WASD moves the Player — the engine's own movement step drives
it, so no Blueprint is required to walk. Before wave GTA1 the capsule had the
controller and not the movement component, which meant no player-controlled
character existed: Play fell back to an overhead camera and nothing moved.

Generated by `inf_editor_core::samples::firstperson_scene`. Regenerate with
`INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.

## What it still does not do (follow-up)

The camera is the engine's **third-person** locomotion camera. `ViewMode` is
camera-side only and never crosses the sim wire, so a level cannot ask for the
first-person one yet; that is the tracked follow-up for a fully first-person
starter, and the `Camera` entity in the scene records the intent meanwhile.
