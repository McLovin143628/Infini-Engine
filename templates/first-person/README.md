# First Person template

The starter scene `inf new --template first-person` scaffolds: a 3D ground
plane, a directional sun, a kinematic **Player** capsule with a
`CharacterController3D`, and a first-person **Camera** at eye height.

Generated by `inf_editor_core::samples::firstperson_scene`. Regenerate with
`INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.

## Wiring up movement (follow-up)

The scene is authored but has no gameplay Blueprint yet. A keyboard mover can
reuse the **character-demo**'s existing host seams — `input.is_down` /
`input.just_pressed` for WASD + jump and `physics3d.move_and_slide` to drive the
controller — via an `.inf_act` on the Player (see `character_demo_class`). True
**mouse-look** additionally needs new input host seams (a mouse-delta node and a
way to write the camera's yaw/pitch), which the node kit does not expose yet;
that is the tracked engine follow-up for a fully playable first-person starter.
