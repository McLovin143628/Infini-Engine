# 2D Platformer template

The starter project `inf new --template 2d-platformer` scaffolds: a ground
collider with a painted tilemap strip, a floating platform, a soft 2D light,
and a player capsule bound to the **Coyote** blueprint (coyote-time jumping).

`Coyote.inf_act` is scaffolded beside the level because the level's
`ActorClass` binding names it; without it the player would not move.

Generated by `inf_editor_core::samples::platformer_scene` +
`coyote_class`. Regenerate with
`INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.
