# The island city (wave I3's benchmark)

Generated by `inf_editor_core::samples::city_scene` and its siblings. **A thousand
buildings on subdivided blocks**, which is the scale the AAA-readiness
certification's IB-2 is about: not "seven buildings cost 28 % of a frame" but what
a city does.

- `City.inf_lvl` -- a sun, the street mesh, a **Driver** carrying
`StreamingSource` (the collider band's anchor, and the same component P16's
cell activation reads), and 100 `PcgVolume` blocks that all point at the one
graph below and differ only by their own `seed`.
- `CityBlock.inf_pcg` -- `grammar.footprint -> building.lots -> building.plan`.
IB-2c's subdivision node is what makes one `building.plan` node ten buildings;
before it, one node was one building and two cities meant thousands of
hand-authored nodes.
- `CityRoads.inf_mesh` -- the street grid through I2's own import door
(`RoadGraph::from_layer -> build_surface -> surface_to_mesh`), one polyline per
segment split at every crossing because `RoadGraph` derives its junctions from
segment ENDPOINTS.

## The ground is flat, on purpose

A terrain would make every building's datum a height query and every measured
number a statement about the terrain sampler as much as about the band. IB-2's
subject is the collider count, so the ground is held constant and the measurement
has one variable. `phase19-town` is the composed scene with real terrain, biomes
and streaming, and it stays that.

## What the gate does with it

`runtime/inf-player/tests/city_scale.rs`: the banded collider count against the
`STREAMED_STEP_BUDGET_MS` the phase-16 gate holds a streamed world to, the
unbanded alternative priced in the same run, the building count and the
subdivision's world proof, and **PIE == shipping on a scripted drive-through**
-- because the collider band is a function of sim state, and a band that read a
camera would make two hosts simulate different worlds.

Regenerate with `INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.
