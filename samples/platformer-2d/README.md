# 2D Platformer sample

Generated by `inf_editor_core::samples` — the Phase-8 gate scene. A small
platformer with a **Blueprint coyote-time jump** that plays in-viewport via the
interpreter.

- `Platformer.inf_lvl` — the scene (tilemap ground + collider ledge + platform +
a kinematic character player).
- `Coyote.inf_act` — the player's blueprint class (BeginPlay + Tick coyote-time
handler), stored as JSON.

Regenerate with `INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.
