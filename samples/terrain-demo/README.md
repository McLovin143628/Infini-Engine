# Terrain Demo (Phase-10 gate scene)

Generated by `inf_editor_core::samples::terrain_demo_scene` — the P10.6 gate
scene: a multi-tile **sculpted + splat-painted** heightfield terrain, a **PCG
scatter volume** (noise+slope rule) referencing `Scatter.inf_pcg`, a directional
sun, and a camera.

- `TerrainDemo.inf_lvl` — the scene as schema-v4 `.inf_lvl` bytes (terrain +
PcgVolume persist).
- `Scatter.inf_pcg` — the scatter graph the volume evaluates on load (its
instances are a derived cache, never persisted in the level).

The terrain heights are `terrain_demo_height(x, z)`; the runtime gate probes
`TerrainData::height_at` against it. The PCG volume's `evaluated` cache is
re-computed on load (editor `pcg_evaluate`, shipped/PIE player `evaluate_pcg_volumes`).

Regenerate with `INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.
