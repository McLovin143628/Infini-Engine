# Character Demo (Phase-11 gate scene)

Generated by `inf_editor_core::samples::character_demo_scene` — the P11.4 gate
scene: an idle/run/jump **state-machine character** driven by a Blueprint across a
sine-hill terrain (the P10→P11 capstone).

- `Character.inf_lvl` — the scene as schema-v5 `.inf_lvl` bytes (SkeletalMesh +
AnimStateMachine + RootMotion + a 3D character controller persist).
- `Character.inf_skel` — a procedural 6-joint humanoid-ish skeleton.
- `Idle/Run/Jump.inf_anim` — three programmatic clips (bob / forward root motion /
vertical arc).
- `Locomotion.inf_sm` — the state machine (idle→run on speed>0.1, run→idle on ≤0.1,
any→jump on jump>0.5 with exit back).
- `Character.inf_act` — the actor blueprint (left/right → move_and_slide across the
terrain via `terrain.height_at`; jump on the rising edge).

The terrain heights are `character_demo_height(x, z)`; the runtime gate scripts
input and asserts the character crosses the terrain (x advances, Y tracks the
height), jumps (Y rises then returns), and its state machine transitions
idle→run→jump. PIE == shipping (identical trace/probes on both paths).

Regenerate with `INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.
