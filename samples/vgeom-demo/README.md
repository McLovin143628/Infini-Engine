# Vgeom Demo (Phase-13 gate scene)

Generated by `inf_editor_core::samples::vgeom_demo_scene` — the P13.4 gate scene: a
grid of `GRID × GRID` instances of ONE dense displaced mesh asset, so the SOURCE
triangle count across instances exceeds 10M while the `.inf_lvl` stays tiny (every
instance references the single `Dense.inf_mesh` by GUID).

- `VgeomDemo.inf_lvl` — the scene (schema v7): instance transforms + `MeshRef.asset`
refs + materials + a sun.
- `Dense.inf_mesh` — the shared ~33k-triangle displaced grid. The cook derives its
`.inf_vmesh` meshlet DAG (via the `MeshRef.asset` dependency-closure edge) and
ships both in the pack.

The gate (`runtime/inf-player/tests/vgeom_gate.rs`): byte-identical save/reload; a
cooked load where the total source triangles ≥ 10M and the GPU meshlet cull leaves
only a small fraction of meshlets visible from a ground-level camera (deterministic
across runs); the SAME pack with vgeom OFF renders through the classic discrete-LOD
fallback (a far camera picks a coarser level than a near one); and the auto-tier
disables vgeom on the Low tier. GPU parts skip cleanly with no adapter.

Regenerate with `INF_BLESS_SAMPLES=1 cargo test -p inf-editor-core samples`.
